Privacy Policy

Last updated: November 10, 2026

This application is a personal, non-commercial integration using rclone and Google Drive.

Data Access

The application accesses Google Drive files and metadata to allow the owner to view, create, edit, download, upload, and delete files.

Data Usage

Google user data is used only for file operations explicitly requested by the owner.

Data Storage

OAuth credentials are stored locally in the rclone configuration on the owner's computer. File data may be cached locally by rclone.

Data Sharing

Google user data is not sold, shared for advertising, or transferred to external analytics services. File transfers occur between the owner's computer and Google Drive.

Access Revocation

The owner can revoke access through Google Account security settings.
